下载游戏（Windows） 如何运行

浪漫童话风

粉金渐变与柔光云朵，呼吸动画的人物立绘，配上击杀与亲吻音效。

轻松上手

方向键移动，碰触恶魔消灭，靠近公主触发彩蛋，用 F11 切换全屏。

暖心彩蛋

通关后，99 条不重复的中文暖心话一条条跳出，填满整个屏幕。

如何运行

  1. 安装 Python 3.11+ 和 pygame（命令：pip install pygame）。
  2. 把游戏文件解压到任意文件夹，双击或执行 python knight_love_game.py。
  3. 遇到字体问题，请把 NotoSansSC-Regular.ttf 放在脚本同目录。
